## 🚀 Utilisation & Cloner avec les Sous-Modules

### Cloner l'ensemble des projets
```bash
git clone --recursive https://github.com/jawedlahrouri/Epitech-Projects.git
cd Epitech-Projects
```

### Initialiser ou mettre à jour les sous-modules après coup
```bash
# Initialiser et cloner les sous-modules manquants
git submodule update --init --recursive

# Mettre à jour tous les sous-modules vers le dernier commit de leur branche
git submodule update --remote --merge
```

### Travailler sur une année spécifique
```bash
# Exemple : accéder à un projet Tek2
cd tek2/Arcade
git checkout main
```
